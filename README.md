# Norrglantan

## Om webbplatsen
Den här är en webbplats som jag har skapat utifrån en given wireframe och en egen mockup som jag har gjort i figma. Målet med webbplatsen var att arbeta med CSS för att skapa en responsiv layout och en tydlig visuell design. Webbplatsen innehåller en startsida med navigation, hero-sektion, information, aktiviteter, kontaktinformation samt bilder. 

## Tekniker som använts
- HTML 
- CSS 
- Flexbox 
- Media queries 
- Git och GitHub
- Figma
